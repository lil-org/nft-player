# Retired review tooling

These are preserved source snapshots of the temporary pass-preparation commands and their tests. The `.txt` suffix prevents execution or automatic test discovery. They are archival evidence, not supported production commands. Their original filenames are retained before the suffix; restore them to their original `tools/` locations only in an isolated historical checkout if reproduction is needed.

The production workflow is documented in `../../../production/README.md`. Review exports and curation records remain in `../../../reviews/` and `../../../rejected.json`. No application review flow remains active.
